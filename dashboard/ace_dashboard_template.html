A.C.E. — AI Concierge & Engine

Phase-1 proof of concept ·
All data on this page is synthetic and illustrative. “Bella Vista Trattoria” is not a real business, the invoices were written for this repository, and the cover history is generated. No pilot deployment has taken place — the working paper describes the 10-location Early Adopter pilot as future work (§4.1, §7). Nothing here is a measured result from a restaurant. Every figure was computed by the code in this repository when the page was built.

Not built — future work

      
    
        
  • OCR. §3.2 specifies a fine-tuned transformer for
          invoice recognition. None is trained. This demo parses a text layer,
          recorded as extraction_method. No OCR accuracy is claimed.
    • 
        
  • Live POS integration. Toast and Clover REST/webhook
          integration is not implemented; Phase 1 is file-based.
    • 
        
  • Trained forecaster. §3.4 specifies a trained
          time-series model with event and weather signals. Not built.
    • 
        
  • Pilot validation. §4.1 and §7 describe a 10-location
          Early Adopter pilot as future work. It has not been run, so this
          repository contains no pilot metrics of any kind.
